description: 清理已合并分支 — 列出已合并分支，确认后删除
---

## 任务
列出所有已合并到当前分支的分支，让用户选择删除。

## 步骤
1. 运行 `git branch --merged` 列出所有已合并分支
2. 排除当前分支和 main/master/develop 等保护分支
3. 展示每个已合并分支的名称、最后 commit 日期
4. 提供交互式选择（可多选）
5. 确认后逐一执行 `git branch -d <branch>`
6. 如果某个分支删除失败（如未完全合并），提示 `-D` 强制删除选项

## 输出格式
```
已合并到 main 的分支：
[x] feat/avatar-upload (最后提交: 2026-05-20)
[ ] fix/login-bug (最后提交: 2026-05-18)
[ ] chore/deps (最后提交: 2026-05-15)

输入编号切换选择，a=全选，d=确认删除选中，c=取消：
```

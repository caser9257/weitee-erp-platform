# MySQL 脚本目录结构

`sql/mysql/` 是当前项目 SQL 维护的主目录。脚本按功能域分目录组织，便于维护和查找。

## 目录结构

```
sql/mysql/
├── README.md                    # 本文档
├── base/                        # 基础初始化脚本
├── finance/                     # 财务模块（凭证、账簿、费用、资产等）
├── mrp/                         # MRP 物料需求计划
├── purchase/                    # 采购模块（入库、质检、批次等）
├── sale/                        # 销售模块（订单、出库、退货等）
├── stock/                       # 库存模块（批次、盘点、调整等）
├── project/                     # 项目管理模块
├── outsource/                   # 委外加工模块
├── system/                      # 系统模块（岗位、部门、租户等）
├── bpm/                         # BPM 审批平台
├── manufacturing/               # 制造模块
├── production/                  # 生产模块
└── misc/                        # 其他独立脚本（文件管理、市场预警等）
```

## 基础初始化

新库初始化执行顺序：

1. `base/quartz.sql` — Quartz 调度表
2. `base/ruoyi-vue-pro.sql` — 基础框架 DDL + 种子数据

## 脚本命名约定

- `NNN-模块-功能.sql` — 编号增量脚本
- `NNN-模块-功能-phaseX.sql` — 分阶段脚本
- `NNN-模块-功能-menu.sql` — 菜单权限脚本
- 无编号脚本 — 独立专项，按需执行

## 重复编号说明

部分编号存在多个脚本（如 100、140、146 等），这些是同一提交批次的不同模块脚本，执行时需结合文件头说明判断。

## 历史说明

- 本轮整理将 153 个散落脚本按功能域分目录
- 清理了 28 个被整合脚本覆盖或一次性修复脚本，保留 125 个核心迁移脚本
- 调整了 7 个放错位置的脚本到正确的模块目录
- 删除了 3 个废弃/一次性脚本（149-erp-file-management-menu.sql、147-erp-reset-2026-06-depreciation.sql、150-erp-file-management-menu-rollback.sql）
- 测试数据、演示数据、验证脚本已从主目录删除
- 历史文档中的旧路径仅作为交付记录参考

## 清理记录

以下类型的脚本已被清理：

- 被整合脚本（146/147/140）覆盖的分阶段脚本
- 一次性修复/回填脚本（已执行过，无需保留）
- 重复版本脚本（如 v2 覆盖 v1）
- 菜单对齐/合并脚本（一次性操作）

清理后的脚本均为核心迁移链，可安全用于新库初始化和增量升级。
